# Claude 세션 대시보드

Claude Code가 로컬에 남기는 기록만 읽어서 실행 중인 세션, 과거 세션, 컨텍스트 사용량,
작업 활동을 한 화면에서 보는 로컬 대시보드.

```
python3 server.py            # http://127.0.0.1:8787
python3 server.py --open     # 브라우저까지 열기
python3 server.py --port 9000
```

의존성 없음. Python 3.11 이상 표준 라이브러리만 쓴다.

---

## 화면

- **Live** — 살아있는 세션 카드. busy/idle, 컨텍스트 사용률, 툴 호출, 마지막 활동 시각.
  SSE로 2초마다 갱신된다
- **Sessions** — 세션 목록. `목록 필터`는 제목·브랜치로 거르고, `본문 검색`은 전체
  트랜스크립트 본문을 훑는다
- **세션 상세** — 컨텍스트 사용량 추이, 토큰 분해, 툴 호출 분포, 대화 타임라인
- **Activity** — 일별 메시지·토큰, 프로젝트별 세션 수, 브랜치별 활성 시간, 모델·툴 집계

탭은 URL 해시에 남아서 새로고침해도 유지된다.

---

## 읽는 데이터

```
~/.claude/sessions/{pid}.json      살아있는 세션 레지스트리 (status: idle/busy)
~/.claude/projects/**/*.jsonl      세션 트랜스크립트
  <sessionId>/subagents/*.jsonl    서브에이전트 트랜스크립트
```

`~/.claude` 아래는 읽기만 한다. 인덱스는 `~/.local/share/cc-dashboard/index.json`에 쓴다.

---

## 아카이브

Claude Code는 `cleanupPeriodDays`(기본 30일)가 지난 트랜스크립트를 **지운다.**
그대로 두면 30일 이전 기록은 통째로 사라진다.

인덱스는 원본이 사라진 세션의 요약을 지우지 않고 `archived`로 표시해 계속 들고 있다.
Activity 집계와 세션 목록은 30일을 넘겨 계속 쌓이고, 상세 화면만 "원본 만료"로 바뀐다.

```
남는 것    제목 · 날짜 · 프로젝트 · 브랜치 · 토큰 · 툴 호출 · 활성 시간 · 일별 집계
사라지는 것  대화 원문 · 타임라인 · 컨텍스트 추이 · 본문 검색 대상
```

세션당 1~2KB쯤 쓴다. 166개 세션에 276KB.

인덱스 파일이 유일한 사본이므로 `~/.cache`가 아니라 `~/.local/share`에 둔다.
`--force`로 전체 재파싱을 해도 아카이브 항목은 유지된다.

`~/.claude/projects` 디렉터리 자체가 없거나 읽을 수 없으면 아무것도 아카이브 처리하지
않는다. 홈 디렉터리가 옮겨졌을 때 인덱스 전체가 만료로 뒤집히는 것을 막기 위해서다.

## 구성

```
server.py     HTTP + SSE. 127.0.0.1 고정 바인딩
index.py      트랜스크립트 인덱서. (size, mtime) 기준 증분 캐시
registry.py   살아있는 세션 스캐너. kill(pid, 0)으로 생존 검증
search.py     전체 본문 검색. 바이트 정규식으로 1차 필터
static/       index.html · app.js · style.css
```

각 모듈은 단독 실행으로 확인할 수 있다.

```
python3 index.py --force      전체 재파싱 + 집계 출력
python3 registry.py           살아있는 세션 목록
python3 search.py kafka       본문 검색
```

## 집계할 때 주의할 점

**한 응답이 여러 줄로 쪼개진다.** Claude Code는 API 응답 하나를 content block마다
별도 jsonl 엔트리로 적고, **모든 엔트리에 같은 `usage`를 반복해서 넣는다.**
줄 단위로 더하면 토큰이 2배 넘게 부풀려진다. `response_id()`로 응답 단위를 묶은 뒤
한 번만 센다.

**소요 시간에는 잠든 시간이 들어있다.** 세션의 첫 타임스탬프와 마지막 타임스탬프
차이는 다음 날 이어서 작업한 경우까지 포함한다. 엔트리 간 간격이 5분 이하일 때만
더한 `activeSec`가 실제 작업 시간이다.

**컨텍스트 한계값은 트랜스크립트에 없다.** `model`이 `claude-opus-5`로만 적혀
`[1m]` 여부를 알 수 없어서, 관측된 최대값이 200k를 넘으면 1M으로 간주한다.

**30일 넘은 세션은 원본이 없다.** 아카이브된 세션은 집계에는 들어가지만 본문 검색
대상에서는 빠지고, 상세 화면은 요약만 보여준다.

## 보안

트랜스크립트에는 DB 비밀번호, 액세스 토큰, 프로덕션 쿼리 결과가 마스킹 없이 들어있다.

- `127.0.0.1`에만 바인딩한다. `0.0.0.0`으로 바꾸지 말 것
- 외부 공개나 터널링 금지
